# 🖼️ گالری من

یک گالری عکس و ویدیوی سبک و خودمیزبان که با PHP ساده نوشته شده است. آن را به یک پوشه روی دیسک خودتان وصل می‌کنید و در یک رابط وب تیره و سریع مرورش می‌کنید. نمایشگر داخلی‌اش از زوم، چرخش، برش و حذف فایل پشتیبانی می‌کند.

بدون دیتابیس، بدون فریم‌ورک، بدون مرحله build، و بدون کش بندانگشتی‌هایی که روی دیسک انباشته شوند.

## ✨ ویژگی‌ها

- **مرور پوشه‌ها:** پیمایش پوشه‌های تودرتو با دکمه بازگشت. پوشه‌ها بر اساس الفبا و فایل‌ها از جدید به قدیم مرتب می‌شوند.
- **عکس و ویدیو:** JPG، PNG، GIF، WebP، MP4، WebM، OGG و MOV.
- **بندانگشتی سریع و بدون ذخیره روی دیسک:** بندانگشتی‌ها در حافظه ساخته و مستقیم به مرورگر ارسال می‌شوند. برای JPEGها در صورت وجود از بندانگشتی تعبیه‌شده در EXIF استفاده می‌شود که بسیار سریع‌تر از دیکود کردن کل عکس است.
- **بارگذاری تنبل (Lazy loading):** فقط بندانگشتی‌های نزدیک به صفحه‌نمایش بارگذاری می‌شوند، پس پوشه‌های با صدها فایل هم روان می‌مانند. برای ویدیوها فریم اول به‌عنوان پوستر نمایش داده می‌شود.
- **نمایشگر Lightbox:**
  - زوم با چرخ ماوس (تا ۶ برابر) حول نشانگر ماوس، جابه‌جایی با کشیدن، و زوم سریع با دابل‌کلیک
  - پخش ویدیو با قابلیت جلو/عقب بردن (پشتیبانی از HTTP Range)
- **ویرایش عکس:** چرخش به چپ و راست و برش (با [Cropper.js](https://github.com/fengyuanchen/cropperjs)). تغییرات به‌صورت اتمیک روی فایل اصلی نوشته می‌شود (ابتدا فایل موقت، سپس rename).
- **حذف فایل** با پنجره تأیید، از داخل نمایشگر یا منوی راست‌کلیک.
- **محافظت در برابر Path Traversal:** هر مسیر درخواستی بررسی می‌شود تا از `MEDIA_ROOT` بیرون نرود.

## 📋 پیش‌نیازها

- PHP نسخه **۸.۰ یا بالاتر** (کد از union return type استفاده می‌کند)
- افزونه‌های PHP:
  - **GD** (ضروری برای بندانگشتی، چرخش و برش، با پشتیبانی از JPEG/PNG/GIF/WebP)
  - **EXIF** (اختیاری، برای مسیر سریع بندانگشتی JPEG)
- یک مرورگر مدرن
- دسترسی اینترنت در مرورگر، چون [Tailwind CSS](https://tailwindcss.com) و [Cropper.js](https://github.com/fengyuanchen/cropperjs) از CDN بارگذاری می‌شوند

## 🚀 راه‌اندازی

1. **دریافت کد**

   ```bash
   git clone <your-repo-url>
   cd <your-repo>/gallery
   ```

2. **تعیین پوشه رسانه** در فایل `config.php`:

   ```php
   define('MEDIA_ROOT', 'D:/Media');   // ویندوز: از اسلش معمولی (/) استفاده کنید
   // define('MEDIA_ROOT', '/home/you/Pictures');   // لینوکس / مک
   ```

3. **اجرا** با سرور داخلی PHP:

   ```bash
   php -S localhost:8000
   ```

   سپس <http://localhost:8000> را باز کنید.

   می‌توانید پوشه `gallery/` را در ریشه وب Apache، Nginx + PHP-FPM، XAMPP، Laragon و مانند آن هم قرار دهید.

## ⚙️ تنظیمات

همه تنظیمات در `config.php` هستند:

| ثابت | مقدار پیش‌فرض | توضیح |
|---|---|---|
| `MEDIA_ROOT` | `D:/Media` | مسیر مطلق پوشه‌ای که نمایش داده می‌شود |
| `IMAGE_EXTS` | `jpg, jpeg, png, gif, webp` | پسوندهای عکس قابل نمایش |
| `VIDEO_EXTS` | `mp4, webm, ogg, mov` | پسوندهای ویدیوی قابل نمایش |
| `THUMB_MAX` | `160` | حداکثر عرض/ارتفاع بندانگشتی‌ها (پیکسل) |
| `THUMB_QUALITY` | `55` | کیفیت JPEG بندانگشتی‌ها (۰ تا ۱۰۰) |

> نکته: `config.php` گزینه `display_errors` را هم فعال می‌کند. اگر گالری را فراتر از سیستم خودتان در دسترس می‌گذارید، آن را خاموش کنید.

## 🗂️ ساختار پروژه

```
gallery/
├── index.php            # رابط کاربری: شبکه پوشه/فایل، Lightbox، منوی راست‌کلیک
├── api.php              # عملیات: چرخش، برش، حذف (پاسخ JSON)
├── serve.php            # ارسال فایل اصلی، با پشتیبانی از Range برای ویدیو
├── thumb.php            # ساخت بندانگشتی در حافظه
├── config.php           # تنظیمات
└── includes/
    └── helpers.php      # مسیر امن، توابع نوع فایل، لیست‌کردن پوشه
```

## 🔌 API

`api.php` درخواست `POST` با پارامترهای `action` و `path` (نسبت به `MEDIA_ROOT`) می‌گیرد و JSON برمی‌گرداند، مثلاً `{ "ok": true, "message": "...", "mtime": 1700000000 }`.

| عملیات | پارامترهای اضافه | توضیح |
|---|---|---|
| `delete` | ندارد | فایل را برای همیشه حذف می‌کند |
| `rotate` | `degrees` (‏`90`، `-90`، `180`) | فقط عکس، فایل دوباره انکود می‌شود |
| `crop` | `x`، `y`، `w`، `h` | فقط عکس، بر حسب پیکسل‌های عکس اصلی |

## ⚠️ نکات مهم

- **احراز هویت وجود ندارد.** هر کسی که به برنامه دسترسی داشته باشد می‌تواند فایل‌ها را ببیند، بچرخاند، برش بزند و **برای همیشه حذف** کند. فقط روی localhost یا شبکه خصوصی مطمئن استفاده کنید، یا قبل از در دسترس گذاشتن آن را پشت احراز هویت (مثلاً HTTP basic auth یا reverse proxy) قرار دهید.
- **چرخش و برش فایل اصلی را بازنویسی می‌کنند** و آن را دوباره انکود می‌کنند (JPEG/WebP با کیفیت ۹۲). از عکس‌های مهم نسخه پشتیبان نگه دارید.
- دوباره‌انکود با GD متادیتای EXIF را از بین می‌برد و انیمیشن GIFها پس از چرخش یا برش از دست می‌رود.
- برای کار کردن چرخش، برش و حذف، پردازش PHP باید روی `MEDIA_ROOT` **دسترسی نوشتن** داشته باشد.
