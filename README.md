# گالری من (My Gallery)

یک گالری سریع عکس و ویدیو در قالب یک پوشهٔ واحد برای PHP (XAMPP یا هر سرور PHP).
تم تیره و روشن، بندانگشتی‌های سبک، و نمایشگر تمام‌صفحه با قابلیت چرخش، برش (کراپ) و حذف.--

## پیش‌نیازها

| مورد | لازم است؟ | توضیح |
|---|---|---|
| PHP 8.0 به بالا | الزامی | |
| اکستنشن `gd` | **الزامی** برای بندانگشتی، چرخش و کراپ | در XAMPP: فایل `php.ini` ← علامت `;` قبل از `extension=gd` را بردارید و Apache را ری‌استارت کنید |
| اکستنشن `exif` | پیشنهادی | جهت عکس‌های گوشی را درست می‌کند |
| اکستنشن `imagick` | اختیاری | بندانگشتی سریع‌تر برای JPEGهای خیلی بزرگ (در صورت وجود خودکار استفاده می‌شود) |
| اتصال اینترنت | الزامی | Tailwind CSS و Cropper.js از CDN بارگذاری می‌شوند |

## نصب

1. پوشهٔ `gallery` را روی سرور خود کپی کنید، مثلاً `C:\xampp\htdocs\Gallery`.
2. فایل `config.php` را باز کنید و پوشهٔ رسانه‌های خود را مشخص کنید (با اسلش معمولی):
   ```php
   define('MEDIA_ROOT', 'D:/Media');
   ```
3. آدرس `http://localhost/Gallery/` را باز کنید.

> روش جایگزین: به‌جای ویرایش فایل، متغیر محیطی `GALLERY_MEDIA_ROOT` را تنظیم کنید.

## قابلیت‌ها

- **پوشه‌ها** با مسیر راهبری (breadcrumb)؛ جستجو (با فشردن `/`)، فیلتر همه / عکس‌ها / ویدیوها، و اندازهٔ بندانگشتی S / M / L.
- **تم روشن / تیره** با دکمه‌ای در سربرگ (انتخاب شما را به خاطر می‌سپارد و در اولین بازدید از تنظیم سیستم پیروی می‌کند).
- **ویدیوها**: بندانگشتی از اولین فریم، نشان مدت‌زمان، و پیش‌نمایش بی‌صدا با رد شدن ماوس در دسکتاپ.
- **نمایشگر** عکس و ویدیو با قبلی / بعدی، زوم (چرخ ماوس / دابل‌کلیک)، جابه‌جایی (pan) و دانلود.
- **چرخش** – فوراً نمایش داده می‌شود؛ ذخیره روی فایل در پس‌زمینه انجام می‌شود (چند کلیک پشت‌سرهم در یک ذخیره ادغام می‌شوند).
- **کراپ** – با انتخاب کل تصویر شروع می‌شود؛ برای کوچک کردن، لبه‌ها را بکشید.
- **حذف** – از نمایشگر یا منوی راست‌کلیک (دائمی است و تأیید می‌گیرد).

### میان‌برها

| کلید | عملکرد |
|---|---|
| `/` | رفتن به کادر جستجو |
| `←` `→` | قبلی / بعدی در نمایشگر |
| `Esc` | بستن نمایشگر / لغو کراپ / بستن پنجرهٔ گفتگو |
| چرخ ماوس، دابل‌کلیک | زوم در نمایشگر |
| راست‌کلیک روی بندانگشتی | منوی زمینه |

## چرا بندانگشتی‌ها سبک می‌مانند

- فقط آیتم‌های نزدیک به صفحه درخواست می‌شوند (بارگذاری تنبل)، **حداکثر ۶ مورد هم‌زمان**؛ آیتم‌هایی که از کنارشان رد شده‌اید از صف حذف می‌شوند.
- `thumb.php` تصاویر کوچک **WebP** (با JPEG به‌عنوان جایگزین) می‌سازد، به‌صورت پیش‌فرض ۲۵۶ پیکسل. چیزی روی دیسک شما ذخیره نمی‌شود.
- زمان آخرین تغییر فایل بخشی از آدرس است، بنابراین مرورگر هر بندانگشتی را یک سال کش می‌کند و دیگر از سرور نمی‌پرسد. وقتی فایلی تغییر کند (چرخش / کراپ)، یک بندانگشتی جدید فقط یک‌بار ساخته می‌شود.
- درخواست‌های شرطی بلافاصله پاسخ `304` می‌گیرند، بدون هیچ پردازش تصویری.
- ویدیوها از رمزگشایی اولین فریم توسط خود مرورگر استفاده می‌کنند – هیچ بار پردازشی روی سرور نیست.
- اگر بندانگشتی‌ای بارگذاری نشود، شبکه به‌جای آیکن خراب، تصویر اصلی را نشان می‌دهد.

## تنظیمات (`config.php`)

| ثابت | پیش‌فرض | معنی |
|---|---|---|
| `MEDIA_ROOT` | `D:/Media` | پوشه‌ای که رسانه‌های شما در آن است |
| `IMAGE_EXTS` | jpg, jpeg, png, gif, webp | نوع‌های تصویر |
| `VIDEO_EXTS` | mp4, webm, ogg, mov | نوع‌های ویدیو (باید توسط مرورگر شما قابل پخش باشند) |
| `THUMB_MAX` | `256` | حداکثر عرض/ارتفاع بندانگشتی به پیکسل (کوچک‌تر = سبک‌تر) |
| `THUMB_QUALITY` | `60` | کیفیت بندانگشتی، از ۰ تا ۱۰۰ |

## فایل‌ها

```
index.php          صفحه، استایل‌ها و تمام منطق سمت کاربر
thumb.php          بندانگشتی‌های لحظه‌ای (WebP/JPEG، کش‌شونده در مرورگر)
serve.php          ارائهٔ عکس‌ها/ویدیوهای اصلی (از جلو/عقب بردن ویدیو پشتیبانی می‌کند)
api.php            چرخش / کراپ / حذف
config.php         تنظیمات
includes/helpers.php   مدیریت امن مسیر، فهرست فایل‌ها، جهت EXIF
```

## خلاصه

1. پوشهٔ `gallery` را داخل `C:\xampp\htdocs\Gallery` بگذار.
2. در `config.php` مسیر عکس‌ها را بنویس: `define('MEDIA_ROOT', 'D:/Media');`
3. اکستنشن GD باید روشن باشد: در `C:\xampp\php\php.ini` خط `;extension=gd` را بدون `;` کن و Apache را ری‌استارت کن.
4. آدرس `http://localhost/Gallery/` را باز کن.
